# Implementation Plan: auto-approval (V1)

Requirements: [requirements.md](requirements.md). Design: [design.md](design.md). Property numbers below are the numbered Correctness Properties in the design; condition numbers 4.2.1 to 4.2.13 are the sub-criteria of R4.2 defined in the design (L8).

Preconditions: the `store`, `services` and `connectors` modules are merged (their `Hub`, `create_app`, `ServiceRegistry`, `ReduceAuditLimiter`, `AuditLog`, `StateView`, `ProposalWriter` exist as designed). This module edits the same regions of `hub.py`, `api.py` and `commands.py` as those modules, on top of their result (design, "Needs from store 1"). Nothing here is committed by the agent.

Design approved 2026-11-18 with every recommended answer (O1 to O10). "Needs from store" items 1, 2, 4 and 5 are coordination notes done inside this module's tasks on top of the finished store code (1: tasks 5.2 and 5.3; 2: task 4.4; 4: task 4.1; 5: task 3.1). Item 3 (`Incident.reopened_at`) is not needed: the up-to-60 s observation lag is accepted (O2).

Conventions for every task: write the tests first and watch them fail, then implement; run the new tests and `python -m pytest -q`; no task edits an existing test except 6.2 (`test_proposals_endpoint_fields`, the one change the requirements allow, R9.7). Tasks marked `*` (Kiro's optional marker, `- [ ]*`) are optional property tests that may be skipped for a faster first pass; every requirement is also covered by a non-optional example test. Every property task **not** marked `*` is required. The optional tasks are 3.3 (property 18), 7.2 (21) and 9.2 (14, 19, 23). Required properties: 1, 2, 3, 4 (2.3); 5, 15, 20 (1.5); 6 (4.3); 7, 10, 11, 12, 13, 16, 22, 24 (9.1); 8, 9 (2.4); 17 (3.2). Success Criterion 7 names 1, 2, 5, 6, 7, 8, 12, 15, 17 and 20; all of them are required. Stack: Python 3.11+, stdlib `sqlite3` through `store` only, FastAPI and pydantic in `approvals/routes.py` only, pytest, Hypothesis (already in the `dev` extra). New files under `src/chimericmesh/approvals/` unless a path is given. Each sub-task touches at most five files. Test helper: `tests/unit/approvals_helpers.py` (created in 4.1, the first task that has a manager) exposes `make_manager(mode)` for `mode in ("bare", "store")`, a `FakeClock` use, and a `FakeLimiter` that records calls.
