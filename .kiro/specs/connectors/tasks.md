# Implementation Plan: connectors (V1)

Requirements: [requirements.md](requirements.md). Design: [design.md](design.md). Property numbers below are the numbered Correctness Properties in the design. Sub-criterion ids (1.1a to 1.1e, 3.3a to 3.3g) are the tables in the design.

Conventions for every task: write the tests first and watch them fail, then implement; run the new tests and `python -m pytest -q`; no task edits an existing test. Two edits touch test files created by earlier modules: task 2.1 adds rows to `tests/unit/test_dependency_direction.py` (created by `store`, extended by `services`) and task 7.1 appends fixtures to `tests/conftest.py`; both are additive and listed in the final checkpoint. This list assumes `store` and `services` are merged first (build order); tasks 2.3 and 8.1 name what to do if a dependency is missing. Tasks marked `*` (Kiro's optional marker, `- [ ]*`) are optional property tests that may be skipped for a faster first pass; every requirement is also covered by a non-optional example test. Every property task **not** marked `*` is required. The optional ones are tasks 1.9 (properties 4, 5, 8), 2.4 (20), 5.2 (16), 6.3 (17) and 7.5 (18, 19, 21), plus 8.6, which is conditional on open item O1. Required: 1, 6, 7 (1.7); 2, 3 (1.8); 9, 10, 11 (3.2); 12, 13, 15 (4.5); 14 (4.6). Success Criterion 4 names property 1; Success Criterion 2 names property 14; both are required. Stack: Python 3.11+, stdlib only (`asyncio`, `os`, `stat`, `re`, `hashlib`, `sqlite3` through the store), pytest, Hypothesis (already in the `dev` extra). No new dependency, no `ctypes`. New format files under `src/chimericmesh/parsers/`, everything else under `src/chimericmesh/connectors/`. Each task touches at most five files.

Review notes (see "Review resolutions" in the design): M1 is task 2.1; M2 is tasks 2.3 (criterion 1.1b to 1.1d) and 8.2 (1.1e); L1 is task 2.3; L8 is the sub-criterion ids used in tasks 2.3 and 4.2; the NTFS rotation identity item is task 4.4 (measured once in the design, repeated here as an automated test).

Round 1 changes (see "Round 1 review resolutions" in the design): 8.6 is new and conditional (not needed: O1 accepted 2026-11-18). Tests changed because the first draft assumed things the platform does not do: the 100 KB frame test follows a valid octet frame (a fresh-connection `102400 ...` frame is LF framing, task 3.3), a rename can fail once while a poll is reading (tasks 4.1, 4.4), `poll_file` maps WinError 32 and 33 to `busy` and `ValueError` to `error` (4.1, 4.2). New behaviour with tests: `header_fields` for W3C (4.1, 7.1), `RawLine.discarding_after` (4.1, 7.1), `raw` without query text (1.3, 1.4), `matched` for syslog-text from the patterns (1.2), counter semantics (7.1), re-enable as a new attach and the duplicate-path guard (7.2), the shutdown deadline (8.1).
